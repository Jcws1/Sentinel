# Submission requirements

Source: [unchanged PDF snapshot](../../raw/inputs/DVL_Final_Deliverables_Guidelines.pdf). Original: `D:\Downloads\DVL_Final_Deliverables_Guidelines (1).pdf`.

Report requirements on PDF pages 2-4 call for a 250-word cover abstract covering the problem, approach, headline quantitative result, and operational implication. They specify an 11-point serif body, single spacing, PDF submission, references excluded from the body count, and optional appendices limited to five pages. IEEE reference style is recommended in the PDF and explicitly required by the user for this report.

User updates in this task take precedence: the organisers favour a concise report and do not require filling ten pages. They emphasise methodology, architecture, and decisions, explained for technically informed judges who are not all software developers. The requested template uses Times New Roman 11-point body text and native Word elements without graphics.

The current abstract request additionally requires evaluation conditions, the boundary between simulation and field evidence, baseline, trial count, uncertainty where available, and a closing practical implication and limitation. See [[wiki/outputs/Abstract]].
