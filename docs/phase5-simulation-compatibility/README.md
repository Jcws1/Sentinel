# Phase 5 simulation compatibility

Phase 5 adds an isolated external batch workflow to the existing workspace.
**Partial delivery; acceptance withheld.** Valid mixed-scale geometry, the full browser gate and independent foreground verification remain open. Final results are tracked
in [VERIFICATION](VERIFICATION.md). This is local compatibility under the frozen
specification and explicitly provisional policies, not organiser certification.

Open **Simulation** from Views. Load a JSON file, paste a request, or load the
NOTIONAL example. Inspect mission, command and calibration identity, then submit.
The notice reports completion only after the response and all authoritative
frames/events commit. Select an external run to inspect its mapped mission and
module-owned Details. BLUE is affiliation; it does not grant control or select a
drone photograph. Existing explicit photo mappings and honest fallbacks remain.

HOLD and ABORT create distinct durable commands from the recorded run input.
RESUME requires an explicit valid batch with a new command identity; HOLD is not
interactive Pause. Select **Load recorded commands** to inspect an earlier result
after ABORT. The full response remains available even though the interaction
table displays bounded pages. This is recorded inspection, not Timeline/replay.

An uncertain response retains the exact original body and command identity in
the separate versioned browser session. Reload and use **Retry exact pending
command**. Do not edit/recreate an uncertain command. A completed identical retry
returns its stored response even after later lifecycle transitions. Corrupt or
unavailable browser persistence blocks sending rather than losing that identity.

External runs have separate internal missions and a backend-enforced writer
claim. Existing Fleet, Orchestrator and moving interactive runs remain separate;
there is no repeated-START streaming bridge. Source MSL values remain labelled
MSL. Existing map h≈H fallback remains an approximation, without terrain-clearance
or altitude-fidelity acceptance.
