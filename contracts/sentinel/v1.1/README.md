# Sentinel internal contracts 1.1

Backend authority: `backend/app/domain/models.py`, `world/contracts.py` and `commands/contracts.py`. Generated by `scripts/export_contracts.py`; TypeScript generated by `frontend/scripts/generate-contracts.mjs`. Deploy the matching frontend and backend together. Strict 1.0 world clients reject 1.1 explicitly.

World/stream are **1.1**. `interactive` is the optional typed **1.0** local-demo module; it is absent for existing fixtures. The complete projection travels in every interactive delta with the other changes. Catalog, observed history, event and recording metadata response versions remain 1.0. No Phase 5 schema is changed.

The frozen `../v1/` schemas and fixture are legacy artifacts. SQLite schema 2 adds interactive checkpoints and immutable creation/command receipts; the reader validates 1.0 stored frames before adapting them in memory. It never rewrites stored legacy JSON. Unknown future database versions reject startup.

See [M1.1 decisions](../../../docs/m1.1/CONTRACT_DECISIONS.md) for the transition matrix, exact public rejection codes, expiry, ownership, clock, migration and compatibility policies.

| Operation | Route |
| --- | --- |
| Template availability / active run | GET `/api/interactive/entry` |
| Idempotent new run | POST `/api/interactive/runs` |
| Original creation receipt | GET `/api/interactive/creations?identity={encodedCreationId}` |
| Current run/control status | GET `/api/interactive/{missionId}/status` |
| Fresh lifecycle/control intent | POST `/api/interactive/{missionId}/intents` |
| Idempotent command | POST `/api/interactive/{missionId}/commands` |
| Original command receipt | GET `/api/interactive/{missionId}/receipts?identity={encodedCommandId}` |

Use the query form for opaque receipt IDs, including dot segments, Unicode and literal percent sequences. Initial path forms remain deprecated compatibility aliases; URL path normalization prevents them from representing every valid ID. The published ID contract is unchanged.

The exact shapes are in `interactive.schema.json` and OpenAPI. Valid parsed admission rejections are immutable receipts with `accepted=false`; they do not change the world. Identity conflicts return HTTP 409. Malformed shape returns 422; missing reads return 404; unavailable storage returns 503 with no committed success. Credentials are supplied only in `X-Sentinel-Control`, held outside journal/world data and never echoed. Receipt reads retain the same local read-access boundary as recordings. This is a single-process local demonstration, not general authentication.
