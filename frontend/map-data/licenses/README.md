# Regional asset notices

These upstream notices accompany the environmental assets reused read-only from Sentinel v2. Retrieved 2026-09-11; `maps:setup` copies this directory into the prepared pack at `edge-map/assets/licenses/`. They do not license Sentinel's application code or Google's hosted data.

- [Protomaps code/style notice](https://github.com/protomaps/basemaps/blob/main/LICENSE.md): `Protomaps-BSD.txt`.
- [Protomaps dataset notices](https://github.com/protomaps/basemaps/blob/main/LICENSE_DATA.md): `Protomaps-data.md`, including OSM/ODbL, Natural Earth, ESA WorldCover landcover and icon provenance. The renderer visibly credits OSM, Protomaps and ESA WorldCover.
- [Noto glyph license](https://github.com/protomaps/basemaps-assets/blob/main/fonts/OFL.txt): `Noto-OFL.txt`.
- [Tangram/Mapzen icon notice](https://github.com/tangrams/icons/blob/master/LICENSE.md): `Tangram-icons-MIT.txt`.
- Terrain uses [Mapterhorn's source attribution](https://mapterhorn.com/attribution/), also linked in the map. DEM decoding and source provenance are described in the archived map-refinement review (see `docs/ARCHIVE.md`); copying these notices does not establish survey accuracy or an altitude datum conversion.

The local style was adapted for Sentinel's neutral palette, selective labels and independent buildings/terrain presentation. Archive data, glyphs and sprites were not edited. Google imagery/tiles remain streamed with their own visible on-screen attribution and are not included in the local pack.
