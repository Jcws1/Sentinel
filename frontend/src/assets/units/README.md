# Supplied unit reference images

The operator supplied these two PNGs for Milestone 1 on 20 September 2026.
`quadcopter.png` is an unchanged copy of `D:/Downloads/Quadcopter_Drone.png`;
`sting-interceptor.png` is an unchanged copy of
`D:/Downloads/Sting_Interceptor_Drone.png`. Application imports use these local
static assets, never the original paths. No new artwork, cropping or geometric
alteration is applied. Source-edge clipping is retained; CSS contains the entire
image against black and reserves equal space for loading/failure states.

`AssetPortrait` maps only `hornet-10-v1` and `sting-v1` profile identities. A
display name, affiliation, mission template or list position does not establish
the photographed model. Other identities receive a text fallback. Images are
static references, independent of simulated telemetry and Video Feed, and are
never included in world frames, checkpoints or receipts.
